## Weekly rhythm

Each week includes a lecture or reading seminar, corpus navigation exercise, source modification laboratory, negative-case analysis, and evidence review. Weeks 6 and 11 include implementation checkpoints. Week 12 is reserved for capstone certification and oral defense.
