# Provenance

The release was derived from the user-supplied `DeepML_Logic_Functional_Language_Coupling_Mechanics_Corpus.jsonl.gz`. That attachment is a wrapper containing rewritten source documents. The release reconstructs those documents under `source_original/`, preserves the wrapper under `corpus/source_wrapper/`, and creates normalized publication artifacts around the embedded 10,000 records.

Generated editorial and organizational material includes the textbook, curricula, catalogs, validators, manifests, suite catalog, governance charter, and release documentation. Source programs in the curated script pack are copied from corpus record `source` fields and retain their source hashes.
