# JA21-DeepML-Logic-Functional-Language-Suite-1.0.0

Connect pure functions, predicates, rules, and proof terms with JA21 DeepML Logic/Functional. Explore 10,000 technical records, 1,000 programs, a 22-chapter textbook, and offline corpus tools across functional programming, logic, proofs, and compiler transformations. Study language design and inference contracts through explicitly modeled outcomes.

The JA21 DeepML Logic/Functional Language Suite brings pure functions, predicates, rules, and proof terms into one structured research and education collection. It is designed for students, instructors, logic-language researchers, and compiler developers who want to examine functional and declarative source examples alongside their expected diagnostics and evidence contracts.

The release contains a 10,000-record normalized technical corpus, twenty 500-record shards, 1,000 source programs, and a 22-chapter textbook. Its 46 topics span six proficiency tiers. Programs are grouped into foundations, functional programming, logic, proofs, systems, compiler transformations, diagnostics, and certification. A curriculum, corpus guide, schema, indexes, feature matrix, diagnostic catalog, and offline inspection tools support classroom work, retrieval, and corpus analysis.

The textbook progresses through theorem evidence, planning, JA21 integration, R12/MCRT lowering, and an offline capstone. Current audit extensions preserve source hashes and qualify modeled outcomes. The supplied package includes no native compiler or runtime; full domain grammar, actual inference, proof discharge, and execution conformance remain separate implementation requirements. Expected proof or runtime labels should therefore be used as study targets.

## Corpora and audit records

The supplied corpus layout is preserved under `payload/`. The `audit/` directory and [AUDIT_AND_UPGRADES.md](AUDIT_AND_UPGRADES.md) record source coverage, release changes, and evidence boundaries.

Historical source archives and source manifests remain provenance records. Current publication file hashes are listed in `PUBLICATION_SHA256.json`; licensing changes are recorded in `PUBLICATION_LICENSE_LEDGER.json`.
